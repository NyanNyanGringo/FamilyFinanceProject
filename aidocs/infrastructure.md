# Документация по инфраструктуре

## Обзор
FamilyFinanceProject использует Docker для контейнеризации и развёртывания, что упрощает запуск как локально, так и на VDS/VPS серверах.

## Архитектура Docker

### Настройка контейнера
- **Базовый образ**: Python 3.11.6-slim
- **Рабочая директория**: `/app`
- **Пользователь**: не-root пользователь `appuser`
- **Проверка здоровья**: кастомный скрипт проверки здоровья с интервалом 30 секунд

### Конфигурация Docker Compose

#### Сервисы
```yaml
familyfinance-bot:
  - Сборка из локального Dockerfile
  - Политика `restart: unless-stopped` при завершении контейнера
  - Ротация Docker json-file логов: до 10 MB на файл, не более 3 файлов
  - Переменные окружения из файла .env
  - Монтирование Google-кредов в режиме read-only
```

#### Volumes
1. **Voice Messages**: `/app/voice_messages`
   - OGA и WAV являются временными файлами одной обработки
   - Приложение удаляет оба файла после успеха, ошибки или отмены обработки
   - Периодическая и историческая очистка отключена; после аварийного завершения остатки проверяются вручную
   - В dev override директория `./voice_messages_dev` монтируется в контейнер

2. **Google Credentials**: `.google_service_account_credentials.json` монтируется в режиме read-only

3. **Logs**: stdout/stderr управляются Docker через драйвер `json-file`

### Недавние улучшения Docker (август 2025)

#### Исправление установки Poetry
- Исправлена проблема, из-за которой Poetry переустанавливался при каждой сборке
- Улучшено кэширование Docker-слоёв: установка Poetry отделена от установки зависимостей
- Процесс сборки теперь корректно кэширует Python-зависимости

#### Обработка прав доступа
- Добавлена аккуратная обработка ошибок при `chmod`
- Обрабатываются случаи, когда права нельзя изменить из-за смонтированных volume'ов
- Предотвращает падение контейнера при старте из-за ошибок прав

## Способы развёртывания

### Локальная разработка
```bash
docker-compose up -d
```

### Продакшен-развёртывание (VDS/VPS)
1. **Деплой одной командой**: `./deploy-simple.sh myvps`
2. **Ручной деплой**: SSH + docker-compose

### Мониторинг здоровья
- Проверка здоровья запускается каждые 30 секунд
- Проверяет доступность бота и базовую функциональность
- Провал health check переводит контейнер в состояние `unhealthy`, но сам по себе не вызывает перезапуск при `restart: unless-stopped`

## Соображения безопасности

### Права файлов
- Приложение запускается под не-root пользователем
- Чувствительные файлы (креды) монтируются в режиме read-only
- Директория `voice_messages` требует прав на запись

### Переменные окружения
- Хранятся в файле `.env` (не коммитится в git)
- Содержит:
  - OPENAI_API_KEY
  - TELEGRAM_TOKEN
  - TELEGRAM_TOKEN_DEV
  - DEV
  - GOOGLE_SPREADSHEET_ID
  - GOOGLE_SPREADSHEET_ID_DEV

## Обслуживание

### Управление логами
- Docker использует драйвер `json-file` с `max-size: 10m` и `max-file: 3`
- Общий объём stdout/stderr логов контейнера ограничен примерно 30 MB
- Просмотр доступен через: `docker compose logs -f`

### Очистка voice_messages
- Приложение удаляет OGA и WAV сразу после обработки каждого сообщения
- Фоновая периодическая очистка не запускается
- Ручная проверка нужна только для файлов, оставшихся после аварийного завершения процесса или контейнера

### Обновление контейнера
```bash
# Скачать последние изменения
git pull

# Пересобрать контейнер
docker-compose build

# Перезапустить с новой версией
docker-compose up -d
```

## Устранение неполадок

### Типичные проблемы
1. **Контейнер не запускается**: проверьте логи `docker-compose logs`
2. **Ошибки прав доступа**: проверьте права для смонтированных volume'ов
3. **Рост использования диска**: проверьте остаточные аудиофайлы и Docker json-file логи
4. **Бот не отвечает**: проверьте ключи API в `.env`

### Команды для отладки
```bash
# Проверить статус контейнера
docker-compose ps

# Запустить health check
docker exec familyfinance-bot /usr/local/bin/healthcheck.sh

# Интерактивная оболочка
docker exec -it familyfinance-bot /bin/bash
```
