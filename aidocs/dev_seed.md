# DEV seed (исторические данные)

## Что делает
- Заполняет лист `⚙️Настройки` базовыми справочниками (валюты, пользователи, банки, счета, категории) в DEV-таблице.
- Генерирует реалистичные операции (расходы, доходы, переводы/adjustments) с 4–7 операций в активные дни, без отрицательных балансов, с прогрессом записи.
- Использует диапазоны *data (`*data!M7:M`, `*data!AK7:AK`, `*data!AL7:AL`) как источники счетов и категорий; `Дата начала таблицы` берется из `⚙️Настройки!C12` (поддерживаются числа Sheets и строки вида `January 1, 2023`).

## Запуск
- Полный цикл (заливка настроек, симуляция, запись):
```
poetry run python -c "from src.dev_seed import run_dev_seed; run_dev_seed(seed=123, overwrite_settings=True, reset=True)"
```
- Только очистить вводные листы (с сохранением шаблонной строки):
```
poetry run python -c "from lib.utilities.google_utilities import reset_dev_input_sheets; reset_dev_input_sheets()"
```
- Тесты симуляции:
```
poetry run python -m unittest discover -s tests -q
```

## Правила генерации
- Валюты (пример): RUB, EUR, USD, CNY, KZT, TRY. Пользователи: БИВИС, БАТТХЕД. Банки: СБЕР, ТИНЬКОФФ, ЯНДЕКС, ОЗОН. Счетов — 8 штук с разными владельцами/типами/банками (заполняются в настройках).
- Доходы: `Зарплата` 1 раз в месяц, `Фриланс` 1–2 раза в месяц (мелкие суммы, могут идти на разные счета).
- Расходы: 4–7 операций в активный день, суммы ограничены (до ~2% месячной зарплаты на транзакцию), выбираются из категорий из *data.
- Переводы: сниженная частота, суммы меньше; Adjustments не более одного на счет в день; корректировка 0 в колонке F, ± в H.
- Стартовые корректировки малы, балансы не уходят в минус (перед расходом/списанием выполняется автопополнение коррекцией при необходимости).
- Прогресс записи: логи вида `Applied batch X/Y (... rows)`.

## Ограничения и рекомендации
- Большие периоды могут не поместиться в один запуск из-за сетевых таймаутов Google API. При необходимости запускайте по частям (например, ограничив период в коде или временно уменьшая batch/период).
- После reset шаблонные строки сохраняются, гарантируется минимум 7 строк на вводных листах.
