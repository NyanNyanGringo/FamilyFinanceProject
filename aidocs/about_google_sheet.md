# Структура DEV Google Sheet

## Доступ и общие правила
- Используется DEV-таблица (`GOOGLE_SPREADSHEET_ID_DEV` при `DEV=1`), доступ через сервисный аккаунт `.google_service_account_credentials.json`, scope `spreadsheets`.
- Вводные листы (`↙️Расходы`, `↗️Доходы`, `🔄Переводы`) имеют заголовок на строке 6. Новая строка вставляется строго над строкой 7, поэтому последние операции всегда под заголовком.
- Дата — серийный номер Sheets (`get_google_sheets_current_date`); статусы: `Committed/Planned`; тип перевода: `Transfer/Adjustment`.
- Основная валюта DEV: `RUB`; округление: 2 знака; дата начала таблицы задается в `⚙️Настройки!C12`; расчеты валют используют историю (включен флаг «Считать валюту по дням»).

## Вводные листы (данные начинаются с 7-й строки)
### ↙️Расходы
- Заголовок: строка 6.  
- Колонки, данные с 7-й строки:  
  - A7:A — `Дата`  
  - B7:B — `Месяц` (формула month)  
  - C7:C — `Категория расходов` (список `*data!AK7:AK199`)  
  - D7:D — `Счет` (список `*data!M7:M199`)  
  - E7:E — `Сумма`  
  - F7:F — `--` (валюта счета, формула)  
  - G7:G — `Статус`  
  - H7:H — `Сумма в основной валюте` (формула пересчета)  
  - I7:I — `-` (код основной валюты)  
  - J7:J — `Комментарий`  
  - K7:K — `Должник`  
  - L7:L — `Telegram Message ID`

### ↗️Доходы
- Заголовок: строка 6.  
- Колонки, данные с 7-й строки:  
  - A7:A — `Дата`  
  - B7:B — `Месяц` (формула)  
  - C7:C — `Категория доходов` (список `*data!AL7:AL199`)  
  - D7:D — `Счет`  
  - E7:E — `Сумма`  
  - F7:F — `--` (валюта счета)  
  - G7:G — `Статус`  
  - H7:H — `Сумма в основной валюте`  
  - I7:I — `-` (код основной валюты)  
  - J7:J — `Комментарий`  
  - K7:K — `Telegram Message ID`

### 🔄Переводы
- Заголовок: строка 6.  
- Колонки, данные с 7-й строки:  
  - A7:A — `Дата`  
  - B7:B — `Месяц`  
  - C7:C — `Тип перевода` (`Transfer/Adjustment`)  
  - D7:D — `Счет списания`  
  - E7:E — `Счет пополнения`  
  - F7:F — `Сумма списания`  
  - G7:G — `-` (валюта счета списания)  
  - H7:H — `Сумма пополнения / Корректировки`  
  - I7:I — `--` (валюта счета пополнения)  
  - J7:J — `Статус перевода`  
  - K7:K — `Комментарий`  
  - L7:L — `Долг возвращен` (булево)  
  - M7:M — `Telegram Message ID`
- Правила для `Adjustment`:  
  - `D` и `E` должны быть одинаковыми (корректировка одного и того же счета).  
  - `F` (сумма списания) всегда `0`.  
  - `H` (сумма корректировки) может быть положительной или отрицательной.

## Конфигурация и справочники
### ⚙️Настройки (видимый)
- Мини-таблица `Настройки валют`:  
  - Диапазон: `A18:B29`  
  - Столбцы: `Код валюты`, `Имя`  
  - Пример: `RUB`, `рубли`
- `Настройки пользователей`:
  - Диапазон: `A33:A42`  
  - Столбцы: `Имя пользователя`  
  - Пример: `ИВАН` (значения пишем капслоком)
- `Настройки конвертов`:
  - Диапазон: `A46:A55`  
  - Столбцы: `Имя конверта`  
  - Пример: `ПОДУШКА` (значения пишем капслоком)
- `Настройки банков`:
  - Диапазон: `A59:A68`  
  - Столбцы: `Имя банка`  
  - Пример: `СБЕР` (значения пишем капслоком)
- `Настройки счетов`:
  - Диапазон: `A72:H133`  
  - Столбцы:  
    - `Имя счета` (формула, не трогаем)  
    - `Связь счетов` (не заполняем)
    - `Валюта счета` (например, `RUB`)
    - `Учитывать в балансе` (булево, `TRUE` для счетов, которые должны попадать в расчеты баланса)
    - `Владелец` (по-дефолту `СЕМЬЯ`, еще пример: `ИВАН`)
    - `Тип` (например, `наличные`)
    - `Имя банка` (например, `СБЕР`)
    - `Имя` (опционально)
- `Категории расходов`:
  - Диапазон: `A137:D158`  
  - Столбцы:  
    - `Категории расходов`  
    - `Ожидаемые траты в месяц` (можно заполнять только для ежемесячных обязательных категорий)
    - `Валюта` (не нужно заполнять)
    - `Использовать в /статус_по_расходам` (булево, `TRUE` только для продуктов и еды вне дома)
- `Категории доходов`:
  - Диапазон: `A170:A179`  
  - Столбцы: `Категории доходов`  
  - Пример: `Зарплата`

### *devconfig (скрытый)
- Ключи: A6:F6 (`_devconfig_default_owner`, `_devconfig_account_types`, `_devconfig_default_expense_category`, `_devconfig_account_ids`, `_devconfig_all_filter_name`, `_devconfig_all_owners_name`).  
- Значения:  
  - A7 — владелец по умолчанию (DEV: `СЕМЬЯ`)  
  - B7:B199 — типы счетов (`наличные`, `карта`, `вклад`, `счет`, `ячейка`, ...)  
  - C7 — дефолтная категория расхода (DEV: `Другое`)  
  - D7:D199 — резервные account_id (DEV: `абрикос`, `лосось`, `песок`, ...)  
  - E7 — фильтр времени (`Все время`)  
  - F7 — фильтр владельцев (`Все владельцы`)  
- Используется как источник дефолтов для *data.

### *data (скрытый, основной хаб именованных диапазонов)
- Заголовок: строка 6; данные/формулы: строки 7–199.  
- Параметры пользователя/даты (одиночные значения):  
  - A7 — `_round_to`  
  - B7 — `_year`  
  - C7 — `_current_month`  
  - D7 — `_current_date`  
  - E7 — `_hide_balance`  
- Валюты (вертикальные списки):  
  - F7:F199 — `_currency_codes`  
  - G7:G199 — `_currency_names`  
  - H7:H199 — `_currency_rate` (live/история)  
  - I7:I199 — `_main_currency` (обычно RUB, дублируется вниз)  
- Пользователи/банки/владельцы:  
  - J7:J199 — `_user_names`  
  - K7:K199 — `_bank_names`  
  - L7:L199 — `_owners` (default + пользователи + конверты)  
- Счета:  
  - M7:M199 — `_account_fullnames`  
  - N7:N199 — `_account_ids`  
  - O7:O199 — `_account_currency_codes`  
  - P7:P199 — `_account_is_active`  
  - Q7:Q199 — `_account_owner`  
  - R7:R199 — `_account_types`  
  - S7:S199 — `_account_banks`  
  - T7:T199 — `_account_names`  
  - U7:U199 — `_account_end_dates`  
  - V7:V199 — `_account_main_currency_codes`  
  - W7:W199 — `_account_filtered_ids`  
- Балансы/итоги по счетам:  
  - X7:X199 — `_account_balance`  
  - Y7:Y199 — `_account_base_balance`  
  - Z7:Z199 — `_account_total_expenses`  
  - AA7:AA199 — `_account_total_write_offs`  
  - AB7:AB199 — `_account_total_adjustments`  
  - AC7:AC199 — `_account_total_incomes`  
- Формула баланса счета: `=ARRAYFORMULA(_account_total_expenses - _account_total_write_offs + _account_total_adjustments + _account_total_incomes)`.
- Категории:  
  - AD7:AD199 — `_expense_category_names`  
  - AE7:AE199 — `_expense_expects`  
  - AF7:AF199 — `_expense_category_currency_codes`  
  - AG7:AG199 — буфер  
  - AH7:AH199 — `_event_expense_category_names`  
  - AI7:AI199 — `_event_expense_expects`  
  - AJ7:AJ199 — `_event__expense_category_currency_codes`  
  - AK7:AK199 — `_expense_categories` (объединенный список)  
  - AL7:AL199 — `_income_categories_names`  
- Фильтры:  
  - AM7:AM199 — `_years_for_filter`  
  - AN7:AN199 — `_owners_for_filter`  
- Ключевые диапазоны для кода: счета `*data!M7:M199`; расходы `*data!AK7:AK199`; доходы `*data!AL7:AL199`.

### *currencies (скрытый)
- Заголовок: A1:F1 (`Дата`, `Валюта`, `Ключ (yyyy-mm-dd|CCY)`, `Коэффициент к базе (история)`, `Валюта (LIVE)`, `LIVE к базе (формула)`).  
- Данные/формулы с 2-й строки:  
  - A2:A — дата курса (серийное число)  
  - B2:B — код валюты  
  - C2:C — ключ `TEXT(A,"yyyy-mm-dd")&"|"&B` (для истории из `*currencies_temp`)  
  - D2:D — коэффициент к базовой валюте по истории  
  - E2:E — актуальные валюты (UNIQUE из `*data!F7:F`)  
  - F2:F — live-курс к базовой валюте (GOOGLEFINANCE)

### #memory (скрытый)
- A1 — текст memories, записи разделены переводами строк.

## Сервисные агрегаты (скрытые)
### *expenses
- Источник: ARRAYFORMULA в A7:G7 подтягивает `Дата, Категория расходов, Счет, Сумма, Статус, Комментарий, Должник` из `↙️Расходы`.  
- Колонки (данные/формулы со строки 6):  
  - A6:A — `_expenses_date`  
  - B6:B — `_expenses_category`  
  - C6:C — `_expenses_account`  
  - D6:D — `_expenses_sum`  
  - E6:E — `_expenses_status`  
  - F6:F — `_expenses_comment`  
  - G6:G — `_expenses_debtor`  
  - H–K — буфер  
  - L6:L — `_expenses_month` (первый день месяца)  
  - M6:M — `_expenses_currency_code` (валюта счета)  
  - N6:N — `_expenses_base_sum` (в базовой валюте, live/история, округление `_round_to`)  
  - O6:O — `_expenses_base_currency_code` (main_currency)  
  - P6:P — `_expenses_account_owner`  
  - Q6:Q — `_expenses_owner` (должник или владелец счета)

### *transfers
- Источник: ARRAYFORMULA в A7:I7 подтягивает `Дата, Тип перевода, Счет списания, Счет пополнения, Сумма списания, Сумма пополнения/корректировки, Статус, Комментарий, Долг возвращен` из `🔄Переводы`.  
- Колонки (данные/формулы со строки 6):  
  - A6:A — `_transfers_date`  
  - B6:B — `_transfers_type`  
  - C6:C — `_transfers_write_off_account`  
  - D6:D — `_transfers_replenishment_account`  
  - E6:E — `_transfers_write_off_sum`  
  - F6:F — `_transfers_replenishment_sum`  
  - G6:G — `_transfers_status`  
  - H6:H — `_transfers_comment`  
  - I6:I — `_transfers_is_debt_returned`  
  - J–M — буфер  
  - N6:N — `_transfers_month`  
  - O6:O — `_transfers_write_off_base_sum` (списание в базовой валюте)  
  - P6:P — `_transfers_write_off_currency_code`  
  - Q6:Q — `_transfers_replenishment_base_sum` (пополнение в базовой валюте)

### *incomes
- Источник: ARRAYFORMULA в A7:F7 подтягивает `Дата, Категория доходов, Счет, Сумма, Статус, Комментарий` из `↗️Доходы`.  
- Колонки (данные/формулы со строки 6):  
  - A6:A — `_incomes_date`  
  - B6:B — `_incomes_category`  
  - C6:C — `_incomes_account`  
  - D6:D — `_incomes_sum`  
  - E6:E — `_incomes_status`  
  - F6:F — `_incomes_comment`  
  - G–J — буфер  
  - K6:K — `_incomes_month`  
  - L6:L — `_incomes_currency_code`  
  - M6:M — `_incomes_base_sum` (в базовой валюте)  
  - N6:N — `_incomes_base_currency_code`  
  - O6:O — `_incomes_account_owner`

## Как данные связаны
- ⚙️Настройки + *devconfig → *data (строит все диапазоны: валюты, владельцы, счета, категории, курсы, фильтры).
- Вводные листы ↙️Расходы/↗️Доходы/🔄Переводы используют списки счетов/категорий из *data и вставляются через API над строкой 7.
- *expenses/*incomes/*transfers подхватывают вводные листы через ARRAYFORMULA и считают месяц, валюты, суммы в базовой валюте на основе *currencies.
- Итоговые диапазоны (`*data!M7:M199`, `*data!AK7:AK199`, `*data!AL7:AL199`, курсы из *currencies, фильтры по датам/владельцам) идут в бота и дашборды для валидации, расчетов и отчетности.
- Настройки заполняются на листе `⚙️Настройки`, но данные для вставки операций берутся из `*data` и других листов, которые начинаются на `*`:  
  - `Настройки валют` → `_currency_codes`  
  - `Пользователи` + `Конверты` → `_owners`  
  - `Банки` → `_bank_names`  
  - `Счета` → `_account_fullnames`  
  - `Категории расходов` → `_expense_categories`  
  - `Категории доходов` → `_income_categories_names`
